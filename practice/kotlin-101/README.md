# Kotlin 101

A small standalone Kotlin exercise covering the language basics: variables and
null safety, collections (`List`, `Map`), loops, `when`, classes, interfaces and
abstract classes.

It is independent of the Android app and the backend and has no Gradle wrapper.

## Requirements

- JDK 21
- Gradle 8.x

## Run

```bash
cd practice/kotlin-101
gradle run
```

The program prints the numbers of a list, the index and value of each element,
and the `forEach` output.
